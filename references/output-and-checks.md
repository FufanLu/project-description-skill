# 输出格式与校验

## 目录结构

```
<输出根目录>/                  示例：~/Documents/面试讲义/
├── <项目名>讲义.html      ← 双击打开。左侧固定目录，滚动时高亮当前章节，窄屏收成「目录」按钮
├── PDF版/<项目名>讲义.pdf ← 第一页是可点目录，带 PDF 书签
├── 配图/                  ← 单独的高清图，中文文件名：<项目名>_<图名>.png / .svg
├── md/<项目名>讲义.md     ← Markdown 原文，图片链接写 ../img/
└── img/                   ← html 用的图，ASCII 文件名：<项目简称>_<图名>.png
```

- 输出根目录让用户指定。多个项目可以共用一个根目录：文件名都带项目名，img/ 里的图带项目简称前缀，互不覆盖。
- 不做 Word。

## Markdown 约定

### 标题和锚点

每个标题上一行放一个 ASCII 锚点，中间空一行：

```markdown
<a id="s1-2"></a>

### 1.2 要解决的问题
```

| 位置 | 锚点 |
|---|---|
| 第 N 章 | `sN` |
| 第 N.M 节 | `sN-M` |
| 第 N.M.K 小节 | `sN-M-K` |
| W 追问 | `wN` |
| 挖坑题 | `qN` |
| 追问分组 / 挖坑分组 | `wg-a` / `qg-1` |

锚点全文唯一、只用 ASCII。GitHub、VS Code、Typora 都能跳。

### 目录块

紧跟在标题区后面，到第一个 `<a id=` 行结束：

```markdown
## 目录

<sub>点标题跳到对应章节；阅读器的大纲栏也能按标题跳。</sub>

- [0 怎么读这份讲义](#s0)
- [1 项目介绍](#s1)
  - [1.1 这是什么](#s1-1)
```

- 缩进 0 / 2 / 4 个空格 = 1 / 2 / 3 级。
- HTML 的侧栏和 PDF 的第一页都从这里生成。条目文字可以比标题短，锚点必须对得上。

### 引用块（提示框）

标题用 `<b>…</b>`，空一行 `>`，再写正文：

```markdown
> <b>为什么先查缓存（W2）</b>
>
> 跳转是读多写少……
```

HTML 和 PDF 按标题上色：「为什么……」蓝；「面试这样说」「一句话答案」绿；「注意」「这一节需要你改」「雷区」「别……」「不要……」红；其他灰。

### 加粗

- 一般用 `**…**`。
- 加粗的内容以标点开头或结尾时（`**「承诺」**`、`**必须先迁移。**`），改用 `<b>…</b>`。CommonMark 的规则下，这种 `**` 紧挨着中文时不生效，会原样显示成星号。
- check_guide.py 会找出没生效的 `**`。

### 标签

`【确定性】` `【Agent】` `【LLM】` `【护栏】` `【人在回路】` 在 HTML 和 PDF 里显示成彩色小标签。别的【】原样显示。

### 表格、图、出处

- 表格用 GFM。单元格里的 `|` 写成 `\|`；要换行用 `<br>`。
- 图：`![图 1 · 系统结构图](../img/xx_arch.png)`；下一段放图注：`<i>图 1 · 系统结构图。一句话说明怎么看。</i>`。
- 出处：`<sub>出处：path/to/file.py · docs/adr/0003.md</sub>`。

## 生成

```bash
SKILL=~/.claude/skills/project-description
ROOT=<输出根目录>; NAME=<项目名>讲义
python3 "$SKILL/scripts/md2html_sidebar.py" "$ROOT/md/$NAME.md" "$ROOT/$NAME.html"
python3 "$SKILL/scripts/md2pdf.py" "$ROOT/md/$NAME.md" "$ROOT/PDF版/$NAME.pdf"
```

- `md2html_sidebar.py`：目录块进左侧栏；图片路径按输出位置重算（`../img/` 变成 `img/`）；点图在新标签页看原图。单文件，没有外部依赖。
- `md2pdf.py`：先渲染成保留目录的 HTML，再用无头 Chrome 打印（`--no-pdf-header-footer --generate-pdf-document-outline`）。A4，底部有页码。目录超过 70 条时只列到放得下的层级，书签里仍是全部标题。`--chapter-breaks` 让每章从新的一页开始。

## 校验

```bash
SKILL=~/.claude/skills/project-description; ROOT=<输出根目录>; NAME=<项目名>讲义
python3 "$SKILL/scripts/check_guide.py" "$ROOT" "$NAME" --numbers
```

| 查什么 | 出错了怎么办 |
|---|---|
| md：每个 `#锚点` 都有 `<a id>`；锚点不重复 | 补锚点或改链接 |
| md：每个标题上一行有锚点（WARN） | 补上 |
| md：有「## 目录」块；每个 `##` 章节都在目录里（WARN） | 按上面的格式补 |
| md：图片路径都存在 | 检查 img/ 和 `../img/` 前缀 |
| md：`**` 加粗都生效 | 改用 `<b>` |
| md：没有没填的模板占位 `{…}`（WARN） | 填上或删掉 |
| html：侧栏每一条都能跳；图片都在 | 重新生成 html |
| pdf：没有空白页；有书签；第一页的目录可点 | 看 pitfalls.md |
| 配图/：有这个项目的 PNG，宽度不小于 2000px | 重新渲染、拷贝 |
| 截图：开头、窄屏、中段、后段四张 | 用 Read 看一眼 |

- `--numbers` 列出正文里所有带数字的行，逐行对照 facts.md，找不到出处的改掉或删掉。
- 只查一份 md：`check_guide.py --md <文件> [--no-images]`。

## 交付时说什么

1. 文件在哪；先双击 `<项目名>讲义.html`；PDF 在 PDF版/，高清图在 配图/，原文在 md/。
2. 代码里核不到的说法，逐条列出。
3. 要用户确认的事实：角色、时间线、有没有上线、简历里的说法。
4. 建议先改的简历措辞（来自雷区表）。
